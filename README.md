============================================================
 سوقنا 📢 — موقع إعلانات مبوبة بقاعدة بيانات مشتركة (Firebase)
============================================================

الفكرة:
- أي شخص ينشر إعلان (عنوان + صورة + سعر + رقم تواصل) فيظهر فوراً
  لجميع الزوار — بدون موافقة أدمن، الإعلانات "تنتشر لحالها".
- قاعدة البيانات مشتركة على سحابة جوجل (Firebase Realtime Database)
  والصور على (Firebase Storage) — يعني الموقع يشتغل من أي جهاز.
- كل إعلان بيه أزرار مشاركة (واتساب / تليگرام / X / نسخ الرابط)
  + عداد مشاهدات + رابط مباشر خاص بكل إعلان.

محتويات المشروع:
  public/                  ← ملفات الموقع (تُرفع للاستضافة)
    index.html             ← الصفحة الرئيسية
    css/style.css          ← التصميم
    js/app.js              ← منطق الموقع
    js/firebase-config.js  ← ★ الصق إعدادات مشروعك هنا ★
  firebase.json            ← إعدادات استضافة Firebase
  database.rules.json      ← قواعد قاعدة البيانات (قراءة/كتابة للجميع)
  storage.rules            ← قواعد تخزين الصور

------------------------------------------------------------
 خطوات التشغيل على استضافة جوجل (Firebase Hosting — مجاني)
------------------------------------------------------------

1) أنشئ مشروع Firebase مجاني:
   - روح إلى https://console.firebase.google.com
   - "إضافة مشروع" ← اسمّه مثلاً souqna ← أكمل الخطوات.

2) فعّل قاعدة البيانات:
   - من القائمة: Build ← Realtime Database ← "إنشاء قاعدة بيانات"
   - اختر الموقع الأقرب لك ← ابدأ بـ "وضع الاختبار" (Test mode).

3) فعّل تخزين الصور:
   - Build ← Storage ← "البدء" ← وضع الاختبار.

4) انسخ إعدادات الويب:
   - ⚙️ إعدادات المشروع ← "إضافة تطبيق" ← اختر ويب ( </> )
   - انسخ كائن firebaseConfig كاملاً
   - الصقه في ملف public/js/firebase-config.js بدل القيم الحالية.

5) ثبّت أدوات جوجل على حاسوبك (مرة واحدة):
     npm install -g firebase-tools
     firebase login

6) ارفع الموقع (من داخل مجلد المشروع ads-website):
     firebase use --add        ← اختر مشروعك من القائمة
     firebase deploy

7) مبروك 🎉 موقعك حي على:
     https://PROJECT-ID.web.app

ملاحظات:
- أول ما يفتح الموقع ستظهر 6 إعلانات تجريبية حتى ترى الشكل —
  احذفها من لوحة Firebase (Realtime Database ← حذف عقدة ads).
- قواعد قاعدة البيانات مفتوحة للقراءة والكتابة حتى تظهر الإعلانات
  للجميع بدون تسجيل دخول. إذا أردت حماية أقوى (تسجيل دخول للنشر)
  اطلبها وسيتم إضافتها.
- رابط أي إعلان: https://PROJECT-ID.web.app/?ad=XXXX — شاركه بأي مكان.
